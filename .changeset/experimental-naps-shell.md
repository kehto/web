Add `ShellAdapter.extensions` for experimental `x-` NAPs. Each declaration has a domain, service, capabilities, a prelude binding and a state. Extensions are validated (`defineShellExtension`, `ShellExtensionError`); advertised, granted and routed like built-in domains; narrowed by `resolveEnvironment` and `disabledDomains`; and report the supported/unconfigured/disabled tri-state through `getShellDomainState`. `renderNappletNamespacePrelude`/`injectNappletNamespacePrelude`/`prepareNappletSrcdoc` accept `extensions` bindings (see `getShellExtensionBindings`). These build a frozen, host-owned `window.napplet[x-*]` from a domain-scoped kit, outside the verified artifact bytes. If `originRegistry.setEnvironment` widens a frame beyond the live environment, it keeps working but warns once (`KEHTO_COMPAT_SHELL_ENV_OVERRIDE`). The package now ships the `kehto-experimental-nap` agent skill under `skills/`. The binding kit accepts only lowercase `x-` action names (the ACL action grammar) and always generates the request id, and the shipped skill warns against secrets in Paja config `settings`.
