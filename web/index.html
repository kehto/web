02 / A small beginning

Bring your ideas.
We brought the parts.

Connect your host adapter. Register the services your apps need. Then load a verified app into its sandbox.

Follow the host tutorial ↗

Nostr is the underlying protocol; NIP-5D describes the napplet apps kernl hosts. Your adapter supplies the backends and policies. The full tutorial covers verification, permissions, and teardown.

host.tsTypeScript 
// 01 — connect your host
import { createShellBridge }
  from '@kehto/shell';
import { createThemeService }
  from '@kehto/services';

const bridge = createShellBridge(adapter);
window.addEventListener(
  'message', bridge.handleMessage,
);

// 02 — give apps a shared theme
const service = createThemeService({
  initialTheme: theme,
});
bridge.runtime.registerService(
  'theme', service.handler,
);
kernl packages currently ship as @kehto/*
