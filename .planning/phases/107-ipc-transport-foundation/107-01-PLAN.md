Create this stable Phase 107 public contract for the expansion plans:

- `createIpcTransport(options?: IpcTransportOptions): Promise<IpcTransport>`.
- `IpcTransport`: `registerEndpoint(registration, hooks): Promise<IpcEndpoint>`, idempotent `unregisterEndpoint(windowId): Promise<void>`, and idempotent `close(): Promise<void>`.
- `IpcEndpointRegistration`: readonly `windowId`, `dTag`, `aggregateHash`, and recursively readonly `environment` metadata.
- `IpcTransportOptions`: optional `baseDirectory`, optional partial `limits`, and optional `onDiagnostic(diagnostic)`.
- `IpcEndpointHooks`: required synchronous `onEnvelope(envelope, registration)`.
- `IpcEndpoint`: readonly `path`, readonly frozen `registration`, `send(envelope): void`, and idempotent `close(): Promise<void>`.
- `DEFAULT_IPC_LIMITS`: `maxPathBytes=90`, `maxFrameBytes=1048576`, `maxBufferedInputBytes=2097152`, `maxOutboundQueueFrames=64`, `maxOutboundQueueBytes=1048576`.
- `IpcTransportError`: typed terminal error carrying an `IpcTransportErrorCode`; diagnostics expose the code and registration identity but omit the full socket path.

No Phase 107 public type accepts peer identity, runtime/session objects, capabilities, or a shared-listener routing key.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Host registration → endpoint factory | Trusted host metadata becomes the immutable binding before filesystem/listener side effects. |
| Local raw peer → pathname socket | Untrusted bytes and wire identity claims cross into the transport decoder. |
| Endpoint → host callback | Only a validated canonical envelope plus the host-frozen binding may cross into host integration code. |
| Host endpoint handle → peer launch/distribution | The filesystem pathname is connection information that must remain in the trusted host topology. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-107-01 | Spoofing | `registerEndpoint` ingress | high | mitigate | Clone/freeze registration before listen, reject own top-level binding keys in every peer envelope, and pass only the bound registration to the endpoint hook; exercise each key in `ipc-shell.test.ts`. |
| T-107-03 | Information Disclosure | Socket pathname and diagnostics | medium | mitigate | Create a mode-0700 private directory, return the path only on the host handle, omit full paths from diagnostics, and document that pathname privacy is not cryptographic authentication. |
| T-107-04 | Elevation of Privilege | Transport/runtime boundary | high | mitigate | Keep runtime/session/capability APIs absent from Phase 107 and admit only canonical object envelopes to the host callback; Phase 108 composes the existing runtime seam. |
