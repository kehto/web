<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Host base-directory option → filesystem | A trusted configuration value still selects where socket resources are created. |
| Filesystem namespace → owned socket handle | Same-UID processes or stale entries can substitute a path between checks. |
| Async listener/socket callbacks → registry | Delayed events can refer to an obsolete generation after replacement. |

## STRIDE Threat Register — ASVS L1, block on high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-107-10 | Tampering | Stale/substituted pathname cleanup | high | mitigate | Retain directory/socket dev+ino fingerprints, re-lstat immediately before unlink/rmdir, refuse non-socket/substituted/out-of-root entries, and exercise real substitution fixtures. |
| T-107-11 | Elevation of Privilege | Caller/path derivation | high | mitigate | Resolve a host base, use `mkdtemp` plus fixed basename, enforce containment/byte length, and never derive from peer or registration identity values. |
| T-107-12 | Denial of Service | Parallel/failed registration | medium | mitigate | Reserve synchronously before awaits, reject duplicates, and roll back only the failed matching generation so a retry can proceed. |
| T-107-13 | Tampering | Delayed cleanup callbacks | high | mitigate | Compare windowId+generation before state or filesystem mutation and prove an old callback cannot touch a replacement. |
| T-107-14 | Information Disclosure | Local socket address | medium | mitigate | Use mode-0700 directories, expose the full path only on the trusted host handle, redact diagnostic paths, and make no cryptographic authentication claim. |
