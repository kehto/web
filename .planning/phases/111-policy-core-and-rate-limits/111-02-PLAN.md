# Pure approval policy

## Objective

Introduce pure, host-neutral permission evaluation in Firewall. Preserve old exports temporarily while runtime and hosts migrate. The new model must never infer a network or resource grant from an old broad allow.

## Decisions

- Principals distinguish verified manifest keys + artifact hashes from explicitly scoped development targets.
- Permissions have category, domain, operation and normalized scope. Interface permissions use the domain itself; resource/network operations also require their interface permission.
- Built-in scopes are exact strings by default, normalized origins and canonical virtual directory paths with segment boundaries. Host extensions supply validated opaque exact keys under an explicit registered category; no wildcard matching by default.
- Deny takes precedence over allow; no matching grant asks. A session grant matches only its endpoint generation; once matches only one request token and is consumed by the coordinator. Persistent grants serialize only durable identities and grants.
- State parsing is strict, bounded and versioned. Malformed state produces an explicit invalid outcome, not broad grants. The runtime owns storage and failure reporting.

## Tasks

1. Implement and export principal/request/grant/state types plus scope validation and matching. Bound input sizes. Never include sensitive resource values in diagnostic text.
2. Implement pure evaluate, grant mutation, revocation and versioned persistence. Every mutation returns detached state; no caller mutation can broaden an already accepted grant. Explicit extension registration fails closed for unknown categories.
3. Cover publisher/artifact/dev isolation, composite interface requirements, denial precedence, scope boundaries, exact operation matching, session/once lifetime, immutable snapshots, round trips, malformed/unknown schemas and resource credentials. Update README/API docs and changeset together.

## Verification

Focused permission unit tests and rate tests; build/type/unit/docs/AI-slop gates at the checkpoint. Record remaining runtime and host work explicitly. No approval UI or protocol behavior is claimed by these pure functions alone.
