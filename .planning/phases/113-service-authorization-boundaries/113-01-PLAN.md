<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Napplet message -> runtime service | Untrusted URL, correlation ID, and bulk list cross into a trusted source-bound handler. |
| Runtime service -> approval coordinator | Validated exact resource identity and actual destination scopes cross into user policy. |
| Browser host -> Paja server transport | An approved URL crosses into the component that resolves DNS and opens the socket. |
| Sandboxed/foreign web content -> Paja proxy endpoint | Untrusted sites and napplets may attempt to call the trusted transport directly and bypass Firewall approval. |
| Paja server -> remote host | DNS answers, redirects, response metadata, and bytes are attacker controlled. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-113-01 | Elevation of privilege | resource-service authorization | critical | mitigate | Runtime-derived principal, exact resource scope, per-hop network requirements, and final lifecycle revalidation enclose cache and body delivery. |
| T-113-02 | Spoofing / SSRF | Paja resource proxy | critical | mitigate | DNS-time public-address validation, address-pinned connection, redirect-by-redirect reauthorization, metadata/private range rejection. |
| T-113-03 | Tampering | canonical resource wire | high | mitigate | Detached input capture, canonical padded-base64 encoding, byte-equal URL correlation, and protocol-specific result validation. |
| T-113-04 | Denial of service | bulk and response processing | high | mitigate | Existing independent temporal budgets plus URL, byte, redirect, timeout, and concurrency bounds; cancel bypasses approval. |
| T-113-05 | Information disclosure | resource cache | high | mitigate | Approval precedes cache access and any cache is partitioned by runtime-bound manifest identity and artifact hash. |
| T-113-05A | Elevation of privilege / CSRF | Paja resource endpoint | critical | mitigate | Server-instance host-only capability, exact Origin/Host/method/content-type checks, no CORS, secret non-disclosure, and rejection before DNS/connection. |
| T-113-SC | Tampering | package supply chain | high | mitigate | No package install; use audited Node built-ins and run the repository slop/quality gate in final phase validation. |
</threat_model>
