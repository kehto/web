<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Napplet request to runtime relay planner | Untrusted filters, hints, templates, recipient, plaintext, ids, and operation type become an immutable candidate plan. |
| Runtime planner to registered service | Approved destinations and current operation generation must remain identical through execution. |
| Runtime authorization to signer/cache/buffer | Local side effects and cryptography must wait for the same live approval as network I/O. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-113-09 | Elevation of privilege | relay destination planning | critical | mitigate | Pure exact-target planning, immutable approved plan, and no execution-time reselection. |
| T-113-10 | Information disclosure | buffer/cache/query delivery | high | mitigate | Runtime approval encloses local delivery and generation guards suppress late results. |
| T-113-11 | Tampering | encrypted/signed publish | critical | mitigate | Approval precedes encryption/signing; snapshot request and revalidate source/generation after each await. |
| T-113-12 | Denial of service | synthesized query | high | mitigate | One top-level authorization/rate charge, direct cleanup, immediate canonical failure, bounded timer fallback. |
| T-113-13 | Spoofing | same-ID subscription replacement | high | mitigate | Exact entry/generation equality for every callback and cleanup path. |
| T-113-SC | Tampering | package supply chain | high | mitigate | No new package installation. |
</threat_model>
