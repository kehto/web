<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Napplet relay request -> selector | Filters, relay hint, templates, recipient, and content are untrusted. |
| Selector -> pool/socket | Candidate relays become actual contacted destinations. |
| Host signer -> relay publish | User identity signs attacker-influenced content for approved destinations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-113-09 | Elevation of privilege | relay selection | critical | mitigate | Approve exact post-selection origins, all fanout targets, and revalidate before connection/signing. |
| T-113-10 | Information disclosure | subscriptions | high | mitigate | Window/source ownership, physical unsubscribe on revoke, and late-event/EOSE suppression. |
| T-113-11 | Tampering | encrypted publish | high | mitigate | Validate and snapshot plaintext/recipient before prompt; sign only inside authorized current action. |
| T-113-12 | Denial of service | relay fanout | medium | mitigate | Independent rate budgets, target deduplication, bounded subscriptions, and abort propagation. |
| T-113-SC | Tampering | package supply chain | high | mitigate | No new package installation. |
</threat_model>
