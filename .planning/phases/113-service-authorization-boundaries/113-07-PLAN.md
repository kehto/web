<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Napplet upload request -> service | Untrusted bytes, names, types, sizes, and hints request identity-linked egress. |
| Candidate selection -> signer/uploader | A selected server becomes an actual signed network destination. |
| Uploader callbacks -> napplet | Progress and URLs may continue after authority changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-113-25 | Information disclosure | upload egress | critical | mitigate | Immutable content metadata/digest plus exact selected-origin approval before signing or bytes leave. |
| T-113-26 | Spoofing | signer identity | high | mitigate | Snapshot and revalidate runtime-owned signer identity inside authorized action. |
| T-113-27 | Elevation of privilege | server discovery/redirect | high | mitigate | Candidate-only discovery, selected-origin approval, and returned/redirected host validation. |
| T-113-28 | Information disclosure | status stream | medium | mitigate | Window/source ownership, targeted revocation, and late-callback suppression. |
| T-113-SC | Tampering | package supply chain | high | mitigate | No new dependencies. |
</threat_model>
