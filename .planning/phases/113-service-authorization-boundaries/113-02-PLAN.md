<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Injected API -> parent wire | Napplet calls become untrusted NIP-5D envelopes. |
| Parent wire -> injected API | Only the authenticated parent may settle pending resource calls. |
| Base64 wire -> browser Blob | Untrusted text becomes bytes exposed to app code. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-113-06 | Spoofing | namespace receiver | high | mitigate | Exact parent-source checks and correlation ownership before decoding or settlement. |
| T-113-07 | Tampering | base64 conversion | high | mitigate | Canonical padded-base64 validation before Blob construction; reject alternate encodings and legacy object payloads. |
| T-113-08 | Denial of service | pending web calls | medium | mitigate | Abort cancellation, bounded pending registry, one-shot cleanup, and late-envelope suppression. |
| T-113-SC | Tampering | package supply chain | high | mitigate | No package installs; existing dependencies only. |
</threat_model>
