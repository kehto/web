<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Napplet FS message -> service | Untrusted virtual paths, handle IDs, and operations cross into host authority. |
| Service -> browser picker/handle | Approved operation invokes user-mediated browser APIs and host-private handles. |
| Watch backend -> napplet push | Filesystem changes may reveal data after authority changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-113-17 | Elevation of privilege | path matching | critical | mitigate | Canonical virtual paths, segment-aware exact/directory scopes, and two-scope move authorization. |
| T-113-18 | Spoofing | handle ownership | high | mitigate | Host-private handle keys bound to window/source generation; wire IDs never establish authority. |
| T-113-19 | Information disclosure | watches | high | mitigate | Requirement-aware close on revoke and current-source guard before every change push. |
| T-113-20 | Denial of service | pickers/watches | medium | mitigate | Independent budgets, bounded ownership maps, abort propagation, and teardown cleanup. |
| T-113-SC | Tampering | package supply chain | high | mitigate | No new dependencies. |
</threat_model>
