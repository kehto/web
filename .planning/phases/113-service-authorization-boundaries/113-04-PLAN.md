<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Outbox/count request -> route planner | Untrusted filters, pubkeys, explicit relays, and templates influence destination selection. |
| Route planner -> relay backend | Discovered/fallback candidates become actual network destinations. |
| Host signer -> outbox fanout | One user-authored signed event is sent to an approved target set. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-113-13 | Elevation of privilege | outbox router | critical | mitigate | Side-effect-free target resolution and approval of every explicit/discovered/fallback destination. |
| T-113-14 | Repudiation / tampering | outbox publish | high | mitigate | Snapshot request, approve before signing, create one event, retain canonical correlation. |
| T-113-15 | Information disclosure | subscriptions/count | high | mitigate | Source-owned live work, abort on revoke, and current-source checks before each send. |
| T-113-16 | Denial of service | relay expansion | medium | mitigate | Target bounds/deduplication and independent operation budgets. |
| T-113-SC | Tampering | package supply chain | high | mitigate | No new dependencies. |
</threat_model>
