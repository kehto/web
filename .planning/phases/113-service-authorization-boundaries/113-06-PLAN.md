<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Napplet request -> device service | Untrusted filters, session IDs, UUIDs, and bytes request privileged hardware actions. |
| Device service -> browser chooser/controller | Approved host code invokes user-mediated hardware APIs. |
| Device callbacks -> napplet | Serial/BLE data may continue after source or grant changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-113-21 | Spoofing | device sessions | critical | mitigate | Host-private opaque keys and source/window generation ownership; never trust supplied IDs alone. |
| T-113-22 | Elevation of privilege | GATT/serial operations | high | mitigate | Distinct exact resource scopes and operation names for select/open/read/write/subscribe. |
| T-113-23 | Information disclosure | device callbacks | high | mitigate | Physical unsubscribe/disconnect on revoke and current-source guard before delivery. |
| T-113-24 | Denial of service | choosers/connections | medium | mitigate | Independent budgets, bounded sessions, abort signals, and teardown cleanup. |
| T-113-SC | Tampering | package supply chain | high | mitigate | No new dependencies. |
</threat_model>
