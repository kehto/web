## Trust Boundaries

| Boundary | Description |
|---|---|
| Runtime prompt to DOM | Security-significant identity, operation, target, and lifetime must be rendered without app-controlled substitution. |
| UI action to runtime management | Presentation invokes authoritative mutation but must not synthesize grants. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-114-05 | Spoofing | approval copy | high | mitigate | Render host/runtime trusted principal and full exact scopes only. |
| T-114-06 | Elevation of privilege | UI state | critical | mitigate | Derive rows from RuntimePermissions and prohibit UI grant storage/evaluation. |
| T-114-07 | Tampering | persistence failure | high | mitigate | Save-before-publish remains runtime-owned; visible fail-closed state and explicit retry. |
| T-114-SC | Tampering | package supply chain | high | mitigate | No package installation. |
</threat_model>
