<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Host resolver to provisional runtime session | Trusted signed or development identity becomes the principal used by admission. |
| Runtime admission to frame commit | A current decision must remain current across every await and at the exact executable-byte boundary. |
| CSP proposal to browser network authority | Remote origins in every source directive become unmediated browser authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-114-01 | Spoofing | provisional identity | critical | mitigate | Bind signed principal or exact development URL plus artifact hash before admission. |
| T-114-02 | Elevation of privilege | resource/direct-network mode | critical | mitigate | `default-src 'none'`, closed directive registry, exact directive-specific requirements, structural denies, and unknown-input rejection. |
| T-114-03 | Tampering | stale admission commit | critical | mitigate | Generation, grant-revision, source, and token revalidation immediately before synchronous commit. |
| T-114-04 | Repudiation | duplicate authorization owner | high | mitigate | Existing runtime coordinator/store owns admission and operation accounting; no shell store. |
| T-114-SC | Tampering | package supply chain | high | mitigate | No package installation. |
</threat_model>
