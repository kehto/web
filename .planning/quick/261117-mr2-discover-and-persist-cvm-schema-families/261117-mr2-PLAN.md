- Website hint: HTTPS origin `/.well-known/napplet.json`, version 1 backend pubkey/relays. CORS required; no proxy. Does not select signaling/ICE or infer family membership.
- Local family label and tool selection are explicit. Default label identifies the provider, never claims a standard family. Saved host-origin entries merge with existing configured families, retaining multiple entries/providers. Discovery does not replace multiplayer configuration.
