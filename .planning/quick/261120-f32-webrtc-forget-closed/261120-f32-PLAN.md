# Quick 261120-f32: forget WebRTC sessions the backend reports closed (kehto/web#492)

Spec: NAP-WEBRTC draft napplet/naps#59, head re-resolved 2026-11-20 = `fb4dd6f0e6294e1837733d2af61931e3e114bd97`
(unchanged). Wire Protocol: "it MUST NOT deliver messages for an unknown `sessionId`". Error
Handling: "The shell SHOULD send a `webrtc.event` with `type: "closed"` when an established
session ends because a peer disconnects, ICE fails, signaling expires, or policy revokes the
capability." `close()`: "Closes the session and asks the shell to publish any corresponding
disconnect signal where appropriate." The text is silent on `closed` for a napplet close, so
#490's behaviour stays as a recorded spec-gap decision.
