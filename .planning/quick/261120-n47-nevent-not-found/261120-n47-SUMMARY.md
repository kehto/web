# Summary

Paja showed `Relay query failed for nevent pointer before complete EOSE: connection failed` when
four relays answered EOSE without the event and one relay was down. nostr-tools reports one close
reason per relay, and the resolver treated any non-EOSE reason as the cause.

- `packages/paja/src/runtime-pointer-outcome.ts`: `classifyPointerMiss`, `tallyPointerRelayReasons`,
  `PajaPointerNotFoundError` (`code: 'pointer-not-found'`, `answered`, `failed`, `relays`).
- `packages/paja/src/runtime-resolver.ts`: uses the classifier; messages for unreachable, timeout,
  and nobody-answered are unchanged.
- `packages/paja/src/runtime-pointer-replacements.ts`: `findPajaPointerReplacements` lists the
  author's current 35129 coordinates (newest per `d`, signature-checked), no Blossom, no install.
- `packages/paja/src/browser-pointer-offer.ts` + `browser-host.ts` + `host-page.ts`: offer button or
  picker under the pointer status; a click calls the existing `loadRuntimePointer(naddr)`.
