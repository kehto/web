# Experimental NAPs on kehto

Goal: GOAL.md (verbatim user goal). Downstream developers build `x-` NAPs on
kehto without changing any kehto package.

## Spec refs checked
- napplet/naps master `43cb3a4e855570ec4b90b9cc05f0c721e5ad0aab`:
  `naps/NAP-SHELL.md` (capabilities.domains, supports()), `projections/web.md`
  (discovery = presence of `window.napplet.<domain>`), `README.md` registry table.
- NIP-5D (nostr-protocol/nips#2303) domain discovery via the web projection.
- Spec gaps (kehto bounded policy, upstream draft only): experimental domain naming
  (`x-` prefix), extension capabilities (`x-<name>:<action>`), host-facing
  `unconfigured` interface state.

## Locked decisions
1. `@kehto/acl`: `x-` reserved namespace. `isExtensionDomain`, `isExtensionCapability`,
   `RESERVED_NAP_DOMAINS` (registry + kehto in-tree domains + retired), `validateExtensionDomain`
   rejects bare names, collisions, and `x-<reserved>` aliases. Grants stored in an
   optional `AclEntry.ext: Record<cap, boolean>` (explicit decisions; missing key falls back to
   default policy). No new bits, `acl-state.ts` bit table untouched. Pure functions
   `checkExtension/grantExtension/revokeExtension`; serialize/deserialize/migrate keep `ext`.
2. `@kehto/runtime`: AclStateContainer/enforce accept `ExtensionCapability`; extension router
   accepts null, built-in, or own-domain `x-` caps; `ServiceHandler.pushCapabilities` declares
   outbound host-initiated types; `sendToEligibleNapplet` is scoped per attached handler; extension
   pushes require own domain + declared type + live session + domain grant + not blocked + ACL +
   firewall (no invented error envelopes).
3. `@kehto/shell`: `ShellExtension {domain, service, capabilities?, binding?, state?}`,
   `defineShellExtension` validation, `ShellAdapter.extensions`; adaptHooks merges extension
   services; build/resolve/getShellDomainState honor them; `resolveEnvironment` still narrows;
   prelude option `extensions: Record<domain, bindingSource>` builds `window.napplet[domain]` via a
   kit scoped to the domain; helper `getShellExtensionBindings`. `originRegistry.setEnvironment`
   keeps working (tested, documented as low-level override).
4. Paja: config `extensions: string[]` module paths (relative to config), served at
   `/__kehto/extensions/<n>.js`, imported by the browser host; module default export is a
   factory `(context) => ShellExtension` with settings. Interface list, toggles, states, parity,
   message log.
5. Playground: `extensions` through demo hooks + ACL panel labels for declared caps.
6. Fixture `tests/fixtures/experimental-nap/` (x-echo), unit + Chromium e2e for Paja and playground.
7. Docs: docs/how-tos/experimental-nap.md + links; compatibility register; upstream proposal draft.
8. Skill `skills/kehto-experimental-nap/` with templates byte-synced to the fixture.
