Spec: NAP-CVM draft napplet/naps#31, head re-resolved 2026-11-20 = `28cf1bdb5c6412bfbfcecb79a5a5121e18376f2f`
(unchanged). Message handling: Notification/Response "After transport publication, result
without `message`; API returns `null`. No MCP response is awaited."; "MUST NOT add an ID to a
notification or rewrite the ID of a napplet's response"; "An ID already used for a client
request in the same MCP session returns \"invalid message\"; a response must match an
outstanding server request delivered to that napplet. An unmatched response returns
\"invalid message\"." Errors: `invalid request` = "Malformed server reference, query, selector,
or other non-message parameter."
