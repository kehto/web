# Summary: approval-phase deadline (kehto/web#457)

The approval coordinator's `timeoutMs` (default 60 s) and `maxPending` slot now cover only the approval phase. Before, they ran through `execute`, so an accepted 120 s NAP-CVM request ended at 60 s with `policy denied`. Equivalent requests also no longer wait for an earlier action to finish, only for its decision. That un-serializes concurrent `cvm.request`s to one server. Running actions stay cancellable. NAP-CVM `timeoutMs` (napplet/naps#31 `28cf1bdb`) now governs the whole operation and expires as `relay timeout`. One open decision: an unanswered prompt is still withdrawn at the host's 60 s cap inside a longer CVM duration.
