# Quick Task 260802-q92: Paja advertised NAP closeout summary

Paja now advertises only domains backed by real browser, network, signer, durable
storage, or host behavior. The previous envelope-only and memory-controller proof
was removed rather than grandfathered.

## Accomplishments

- Replaced serial and BLE memory controllers with Web Serial and Web Bluetooth,
  including chooser activation, streams/GATT operations, disconnect events,
  redacted session identifiers, and per-window cleanup.
- Implemented WebRTC with real peer connections and data channels, signed kind
  25050 Nostr signaling, NIP-44 encrypted SDP, consent, replay/freshness checks,
  limits, signer identity binding, and teardown.
- Replaced canned COMMON, LISTS, CVM, NOTIFY, CONFIG, RESOURCE, UPLOAD, and COUNT
  behavior with real Nostr/browser/host boundaries or a deliberately bounded
  advertised subset.
- Made relay/outbox behavior live-only, removed fixture contamination and local
  publish echoes, implemented scoped subscriptions and stateful relay tiers, and
  reported actual observed relay provenance.
- Removed the default no-op intent host and runtime fallback claims; identity,
  theme, keys, media, notification, storage, link, and intent capabilities now
  disappear when their concrete backend is unavailable.
- Replaced the old simulated all-domain E2E with real Blossom, live-relay,
  mandatory-shell, signer, and fail-closed capability checks.
