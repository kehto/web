# Plan: Paja retires admitted frames through the bridge revoke teardown

1. Reproduce: a real-bridge unit test that admits a Paja frame, binds `napplet.hello` over a real
   `MessageChannel`, retires it by revoking its grant, then checks the session, service
   `onWindowDestroyed`, origin/port and the bridge revoke hook.
2. Pass `ShellBridge.revokeNapplet(windowId, 'host')` into `navigateFrame` (launch options object)
   from runtime tabs, the single frame and the intent launcher; `onRetire` blanks the frame, clears
   Paja's registration, then revokes.
3. `handlePajaNappletRevoked` always drops the window from `readyWindowIds`; Paja logs its own `host`
   revokes as `paja.napplet.retired` so `paja.napplet.revoked` stays the NIP-5D evidence diagnostic.
4. Docs (`docs/packages/paja.md`, `docs/compatibility.md`) and a `@kehto/paja` patch changeset.
