## Trust Boundaries

| Boundary | Description |
|---|---|
| Test → reference host process | The test controls only base directory and termination mode; it must not inject identity or result data. |
| Reference host → raw child arguments | The trusted host distributes one private pathname out of band; possession remains routing, not authentication. |
| Raw socket bytes → runtime | Untrusted child framing reaches the existing bounded decoder, exact readiness gate, frozen registration, ACL, and service dispatch. |
| Service context → IPC egress | A runtime-originated push must pass recipient mapping, domain, live-session, and ACL checks before targeted egress. |
| Child exit/signal → lifecycle cleanup | Untrusted or asynchronous termination may retire only the matching connection/session and owned carrier resources. |
| Child/host stdout → test evidence | Machine-readable records must be bounded, deterministic, and stripped of path/identity secrets. |

## STRIDE Threat Register — ASVS L1, block on high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-109-01 | Spoofing | Raw child identity | high | mitigate | Pass only the pathname, retain the frozen host registration, reject peer binding claims in production, and assert the child receives no identity-selection argument. |
| T-109-02 | Tampering | Request/result evidence | high | mitigate | Require a canonical intent.available request to traverse Runtime.handleMessage and a registered service before the same-id result reaches the child; prohibit a host/test echo path. |
| T-109-03 | Elevation of Privilege | Runtime-originated push | high | mitigate | Retain ServiceRuntimeContext from onRegistered, require sendToEligibleNapplet to return true, and assert the canonical recipient-mapped intent.changed arrives through targeted egress. |
| T-109-04 | Denial of Service | Spawned child and pipe lifecycle | high | mitigate | Drain both pipes immediately, install listeners before signalling, use bounded waits, terminate only the exact child on timeout, await exit, and always close the composition. |
| T-109-05 | Information Disclosure | Transcript and diagnostics | medium | mitigate | Emit named safe milestones and cleanup booleans only; never print pathname, registration, socket, environment internals, tokens, queues, or arbitrary raw frames. |
| T-109-06 | Repudiation | Graceful vs abrupt cleanup claim | medium | mitigate | Run independent process cases, record the actual exit signal, assert cleanup before recursive test cleanup, and reject a non-SIGKILL exit in the abrupt case. |
| T-109-07 | Spoofing | Same-UID pathname access | low | accept | Preserve the documented Phase 107 limitation: private path distribution is operational containment and does not authenticate hostile same-UID processes. |
