|---|---|
| Peer close/error callback → projection state | An asynchronous old callback may arrive after a new peer/session owns the same windowId. |
| Projection teardown → runtime lifecycle | Per-window cleanup must remove subscriptions/services/INC state before identity unregister, without invoking runtime-wide destruction. |
| Ready canonical traffic → runtime policy gates | Environment, host eligibility, ACL, firewall, and capability resolution must retain established ordering. |
| Runtime survivor notification → sibling peer | Cleanup-generated NAP-INC egress must reach only an eligible current sibling endpoint. |

## STRIDE Threat Register — ASVS L1, block on high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-108-07 | Tampering | Delayed peer close | high | mitigate | Compare windowId plus current connection generation, retire current state before callbacks, and prove an old close cannot unregister a replacement session. |
| T-108-08 | Denial of Service | Partial per-window cleanup | high | mitigate | Centralize teardown order as destroyWindow then session unregister and verify subscriptions, services, NAP-INC channels, and routes are removed. |
| T-108-09 | Elevation of Privilege | Post-ready dispatch | high | mitigate | Exercise immutable environment domains, host isDomainAllowed, ACL block, and runtime capability resolution through the real public Runtime. |
