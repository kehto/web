<interfaces>
Public seams to consume without changing their owners:

- `createRuntime(hooks: RuntimeAdapter): Runtime`
- `Runtime.handleMessage(windowId: string, msg: unknown): void`
- `Runtime.destroyWindow(windowId: string): void` performs per-window subscription, INC, and service cleanup but does not unregister the SessionRegistry entry.
- `Runtime.destroy(): void` is runtime-wide and is reserved for composition shutdown after all endpoint teardown.
- `Runtime.sessionRegistry.register(windowId, entry)` and `.unregister(windowId)` are the public source-identity lifecycle seam.
- `RuntimeAdapter.sendToNapplet(windowId, message)` identifies the destination outside the canonical envelope.
- `createIpcTransport()` already exposes `registerEndpoint`, `unregisterEndpoint`, and `close`; the shell composition must bind those carrier operations to runtime teardown rather than exposing the raw transport as the host lifecycle API.
- Existing `createIpcShellProjection({ registration, runtimeAdapter, ...transportOptions })` callers receive `path`, frozen `registration`, `runtime`, and idempotent `close()` and must remain source- and behavior-compatible.
- Existing NAP-INC runtime behavior sends `{ type: 'inc.channel.closed', channelId, reason: 'peer destroyed' }` to the survivor during `Runtime.destroyWindow(destroyedWindowId)`.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Raw IPC peer → endpoint record | Untrusted canonical ingress must be attributed only by the host-held endpoint/peer generation and frozen registration. |
| Shared runtime egress → endpoint map | A runtime-selected windowId must resolve to one current ready peer without broadcasting or leaking sibling metadata. |
| Peer/endpoint terminal event → runtime lifecycle | Asynchronous stale callbacks must not destroy replacement or sibling state. |
| Runtime per-window teardown → carrier release | NAP-INC survivor notification and service/subscription cleanup must occur before identity unregister and physical endpoint deletion. |
| Composition shutdown → shared runtime | Host-wide close must clean every current endpoint once before the one runtime-wide destroy. |

## STRIDE Threat Register — ASVS L1, block on high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-108-13 | Spoofing | Shared endpoint ingress | high | mitigate | Bind callbacks to the transport-frozen registration object and current private endpoint/peer generation; reject all peer identity claims before dispatch. |
| T-108-14 | Information Disclosure | Shared RuntimeAdapter egress | high | mitigate | Resolve one current ready record by host-selected windowId and send only through its opaque peer; assert no cross-endpoint frames or IPC sidecars. |
| T-108-15 | Tampering | Stale peer/endpoint close | high | mitigate | Compare record identity plus generation, retire before callbacks, and prove delayed old peer and old endpoint handles cannot affect replacements. |
| T-108-16 | Denial of Service | Partial lifecycle teardown | high | mitigate | Enforce and spy on destroyWindow then session unregister then carrier release for each exit; keep peer-only exits reconnectable. |
| T-108-17 | Denial of Service | Composition shutdown | medium | mitigate | Snapshot current records, reuse idempotent per-endpoint close promises, await them, and call runtime.destroy exactly once last. |
| T-108-18 | Elevation of Privilege | Cross-endpoint NAP-INC | high | mitigate | Delegate channel open, recipient ACL/capability authorization, teardown, and survivor envelope creation entirely to the unchanged public Runtime. |
