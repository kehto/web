<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Host options/registration → IPC projection | Trusted adapter and recursively frozen registration define identity, environment, and runtime policy before listening. |
| Accepted Socket → opaque peer | Untrusted local connection gains only a queue-bound targeted handle; pathname possession is not authentication. |
| Decoded envelope → readiness/session state | Exact readiness may mutate runtime identity state once; all other pre-ready traffic must be inert. |
| Runtime egress → active peer queue | ACL/capability-qualified runtime output must reach only the current ready peer for the target windowId. |

## STRIDE Threat Register — ASVS L1, block on high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-108-01 | Information Disclosure | Endpoint broadcast vs targeted runtime egress | high | mitigate | Give each accepted Socket one opaque queue-bound sender, reject a concurrent projection peer, and test that init/runtime output is invisible to the rejected peer. |
| T-108-02 | Spoofing | Ready/session identity binding | high | mitigate | Accept only exact bare readiness and build SessionEntry solely from the frozen host registration plus host crypto; retain the Phase 107 peer-claim terminal guard. |
| T-108-03 | Elevation of Privilege | Pre-ready runtime ingress | high | mitigate | Drop non-ready envelopes before Runtime.handleMessage and assert zero session, service, ACL audit, diagnostic, and egress effects. |
| T-108-04 | Tampering | Canonical envelope path | high | mitigate | Forward the decoded NappletMessage object unchanged under host windowId and keep peer/token/diagnostic data outside the wire object. |
| T-108-05 | Repudiation | Payload-bearing readiness | medium | mitigate | Emit one stable redacted code tied only to registered identity while preserving connection and leaving session state unchanged. |
| T-108-06 | Spoofing | Host-held Unix-socket pathname | low | accept | Preserve the documented Phase 107 boundary: the private path is a routing handle and offers no hostile-same-UID authentication; Phase 108 makes no stronger claim. |
| T-108-SC | Tampering | First-party workspace dependency | high | mitigate | Resolve only `@kehto/runtime@workspace:^`, verify its local package name/public exports, refresh the lockfile, and perform no external package installation. |
