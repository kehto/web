<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Host registration → endpoint registry | Trusted host metadata becomes immutable private state before listener side effects. |
| Raw socket chunks → decoder buffer | Arbitrary byte boundaries and volumes enter package-owned memory. |
| Framed bytes → UTF-8/JSON parser | Encoding and syntax interpretation can create parser differentials. |
| Parsed JSON → host callback | Only canonical objects without peer binding claims may cross with the host-frozen registration. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-107-02 | Tampering | Endpoint registry cleanup | high | mitigate | Associate each record/callback with a private generation and compare both windowId and generation before any remove/close action. |
| T-107-05 | Denial of Service | Decoder buffer/frame growth | high | mitigate | Enforce aggregate and per-frame byte limits before decode/parse, validate safe-integer limits, clear bytes on terminal failure, and test exact/+1 thresholds. |
| T-107-07 | Tampering | Parser recovery/resynchronization | high | mitigate | Enter an irreversible terminal decoder state after the first invalid record and prove a later valid frame cannot dispatch. |
