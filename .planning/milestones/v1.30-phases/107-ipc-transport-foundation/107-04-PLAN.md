## Trust Boundaries

| Boundary | Description |
|---|---|
| Host/runtime-originated envelope → queue | Trusted producer can still burst faster than a local peer consumes. |
| Package queue → Node writable buffer | `write(false)` transfers bytes into Node-managed memory and requires drain coordination. |
| Drain/write callbacks → queue state | Reentrant or stale callbacks can duplicate/reorder writes or revive a closed peer. |
