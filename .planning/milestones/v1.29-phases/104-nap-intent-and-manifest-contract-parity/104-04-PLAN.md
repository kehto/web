## Trust Boundaries

| Boundary | Description |
|---|---|
| Service registration → runtime-owned context | Service receives privileged identity and target-send closures. |
| Authenticated source envelope → resolver | Untrusted normalized fields and payload cross into selection. |
| Policy gate → source result | Denial must use sanctioned shape without leaking internal policy. |
| Resolver accepted outcome → source/target lifecycle | Ordering determines whether responsibility and delivery claims are truthful. |
| Resolver change → loaded clients | Installed-catalog information must reach only eligible current sessions. |
